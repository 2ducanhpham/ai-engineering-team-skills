# UI/UX Design

## Discover
1. Identify user, task, context, frequency and consequence of error.
2. Map the current flow and friction points.
3. Inspect existing design system, typography, spacing, color, components and navigation.
4. Separate usability problems from visual preferences.

## Design
- Establish one primary action per screen where possible.
- Make hierarchy obvious: title, context, content, action.
- Prefer progressive disclosure over dense screens.
- Use consistent spacing, typography, surfaces, elevation and interaction patterns.
- Design loading, empty, error, disabled, success and permission states.
- Use clear, natural language; avoid jargon and ambiguous labels.
- Ensure touch targets, contrast, focus order and readable text.
- Consider small screens, long localized strings, keyboard, safe areas and dynamic type.

## Deliver
Current problems ranked by impact, proposed flow, component-level recommendations, states, responsive behavior and acceptance criteria.
Do not invent product behavior or redesign unrelated screens without reason.
