# Accessibility

- Use semantic controls and meaningful accessible names.
- Ensure interactive elements work with keyboard, screen readers and platform assistive technologies.
- Do not communicate state using color alone.
- Check text and control contrast against applicable WCAG guidance.
- Support text resizing and avoid clipping at larger font scales.
- Provide visible focus and logical focus order.
- Label form fields, explain errors and associate errors with inputs.
- Provide alternatives for meaningful images and mark decorative imagery appropriately.
- Respect reduced-motion preferences.
- Verify touch target size and spacing.
- Test representative flows with VoiceOver/TalkBack or available automated checks.

Report concrete barriers, affected users, severity and recommended fixes.
