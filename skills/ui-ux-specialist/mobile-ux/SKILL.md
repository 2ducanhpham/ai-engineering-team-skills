# Mobile UX

1. Test the smallest supported viewport and at least one typical viewport.
2. Respect safe areas, status/navigation bars, keyboard and device insets.
3. Keep primary actions reachable and avoid gesture-only critical actions.
4. Use platform conventions where they improve predictability; maintain cross-platform consistency where appropriate.
5. Handle long text, localization, font scaling and accessibility settings.
6. Define behavior for loading, offline, retry, permission denial and interrupted flows.
7. Prevent accidental destructive actions; provide confirmation and undo when appropriate.
8. Review scroll behavior, sticky headers, bottom sheets, tab navigation and back behavior.
9. Specify measurable layout and interaction acceptance criteria.
