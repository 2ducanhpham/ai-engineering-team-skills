# Evidence-Based Reporting

- Label statements as VERIFIED, INFERRED, ASSUMED or UNKNOWN when ambiguity matters.
- Cite repository paths and line ranges where possible.
- Include exact commands run and summarize their real exit status/output.
- Distinguish tests not run from tests failed.
- Never fabricate screenshots, logs, tool calls, test results, review approvals or delegated work.
- For findings, include impact, likelihood, confidence and remediation.
- State limitations: unavailable environment, missing credentials, unsupported platform or incomplete coverage.
- End with a clear status: PASS, PASS WITH CONDITIONS, FAIL or BLOCKED.
